# МолдМастер - Веб-сайт

Проект создан на Next.js (App Router), Tailwind CSS, React и Supabase.

## Инструкция по настройке

### Шаг 1. Настройка базы данных Supabase

Для корректной работы приложения необходимо создать таблицу заявок (`leads`) в вашей базе данных Supabase.

1. Зайдите в панель управления вашего проекта в [Supabase](https://supabase.com/).
2. Перейдите в раздел **SQL Editor** (редактор SQL) в левом меню.
3. Нажмите **New query**.
4. Скопируйте всё содержимое из файла `database/schema.sql` (в корне этого проекта) и вставьте его в редактор.
5. Нажмите кнопку **Run** в правом нижнем углу, чтобы выполнить скрипт. В результате будет создана таблица `leads`, включен Row Level Security (RLS) и настроены нужные политики.
6. Перейдите в раздел **Project Settings -> API** и скопируйте ключи: `Project URL`, `anon / public` и `service_role / secret`. Добавьте их в файл `.env.local` в корне проекта:
```env
NEXT_PUBLIC_SUPABASE_URL=ваш_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=ваш_anon_key
SUPABASE_SERVICE_ROLE_KEY=ваш_service_role_key
```

### Шаг 2. Инициализация Git и пуш в GitHub

Чтобы инициализировать репозиторий, зафиксировать изменения и отправить их на GitHub, выполните следующие bash-команды в терминале (предварительно создав пустой репозиторий на GitHub):

```bash
# Инициализация нового Git-репозитория
git init

# Добавление всех файлов в индекс
git add .

# Создание первого коммита
git commit -m "Инициализация проекта МолдМастер"

# Переименование ветки в main (по умолчанию)
git branch -M main

# Добавление ссылки на ваш удаленный репозиторий GitHub
# ЗАМЕНИТЕ ссылку ниже на ваш реальный URL репозитория
git remote add origin https://github.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/ВАШ_РЕПОЗИТОРИЙ.git

# Отправка кода в удаленный репозиторий
git push -u origin main
```
